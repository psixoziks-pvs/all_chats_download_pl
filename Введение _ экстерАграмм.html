Введение

Разработка плагинов на языке, который уже используют большинство моддеров Telegram.

Плагины exteraGram

Плагины exteraGram написаны на Python и запускаются внутри приложения через встроенный движок плагинов.

SDK в этом репозитории работает на базе Chaquopy v16 для взаимодействия с Python и подключения методов в стиле Xposed.

Текущий базовый уровень

  • Текущая версия SDK в этом репозитории: 1.4.4.3
  • Среда выполнения Python: 3.11
  • Рекомендуемая минимальная версия приложения для этого SDK: exteraGram 12.5.1+

Версия приложения имеет значение

Если сборка приложения слишком старая, SDK переходит в безопасный режим, а модули плагинов отказываются инициализироваться. На практике при написании12.5.1+ или тестировании новых плагинов на основе этого дерева следует рассматривать его как базовый уровень.

Что вы можете сделать с помощью SDK

  • зарегистрируйте крючки жизненного цикла плагина высокого уровня BasePlugin
  • перехват запросов, ответов, обновлений и исходящих сообщений
  • создавайте страницы настроек плагина и строки пользовательских настроек
  • показывать диалоги и бюллетени в стиле Telegram
  • отправлять или редактировать сообщения и медиафайлы
  • отражаются в классах и полях Java
  • методы и конструкторы Java-перехватчиков
  • сгенерируйте прокси-классы Java из Python с помощью class proxy

Краткий обзор основных модулей

  • base_plugin: метаданные, жизненный цикл, хуки событий, пункты меню, помощники Xposed
  • android_utils: помощники потоков пользовательского интерфейса, оболочки слушателей, ведение журнала, буфер обмена
  • client_utils: запросы, контроллеры, очереди, отправка и редактирование сообщений
  • file_utils: каталоги плюс простые помощники ввода-вывода файлов
  • hook_utils: помощники по рефлексии для классов и частных полей
  • ui.*: диалоги, бюллетени, настройки
  • extera_utils.*: прокси-сервер класса DSL, помощники по форматированию текста, утилиты метаданных
