all_chats_download.plugin — плагин для AyuGram (Telegrah API)

Содержимое архива (.plugin = zip):
  plugin.py     — код плагина (точка входа: async init_plugin(ctx, state_dict))
  plugin.toml   — манифест: id/name/version/entrypoint/icon/permissions
  icon.png      — иконка: значок загрузки ⬇ с эмодзи сообщения 💬 снизу справа
  README.txt    — этот файл

Установка в AyuGram:
  1. Скачайте all_chats_download.plugin на устройство.
  2. AyuGram → Настройки → Плагины (Plugins) → «Установить плагин» / + →
     выберите файл all_chats_download.plugin.
     (Либо распакуйте архив в каталог плагинов: <data>/ayu/plugins/all_chats_download/)
  3. Перезапустите клиент / включите плагин переключателем.

Использование:
  Откройте чат или группу → меню «три точки» → «💾 Скачать чат».
  История выгружается в фоне пачками по ~100 сообщений; во время выгрузки
  показывается счётчик «Загружено X / Y» с кнопкой «Отменить».
  Готовый файл сохраняется в папку «Загрузки»:
      chat_НазваниеЧата_2026-10-09.txt
  По завершении — диалог «Чат экспортирован…» с кнопками
  «📂 Открыть папку» и «ОК».

Формат файла:
  Чат: Название
  Экспортировано: 2026-10-09 15:30
  Всего сообщений: 12453
  ─────────────────────────────
  [2024-01-01 10:15] Иван: Привет
  [2024-01-01 10:17] Иван: [фото]

Запасной способ запуска (если хост не даёт menu-колбэки): команда
/download_chat (или !export) в открытом чате.

Проверка без Telegram: python tests/test_plugin.py
(и ACD_CANCEL_AT=1 python tests/test_plugin.py — сценарий отмены).

Пересборка архива: bash build_plugin.sh
